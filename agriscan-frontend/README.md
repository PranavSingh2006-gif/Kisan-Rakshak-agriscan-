# AgriScan Frontend (Kisan Rakshak Client)

React + Vite + Tailwind CSS responsive web application for Kisan Rakshak crop diagnostics, progressive health tracking, and smart irrigation.

## Quickstart

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

The app runs on **http://localhost:5173** and automatically proxies API requests (`/api/*`) to the backend at `http://localhost:5000`.
